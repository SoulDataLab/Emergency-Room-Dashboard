# Emergency-Room-Dashboard
## 1. Project Title / Headline

**Hospital Emergency Room Analytics Dashboard**

An interactive Power BI dashboard designed to analyze emergency room operations, patient flow, waiting times, admissions, referrals, and patient satisfaction.

---

## 2. Short Description / Purpose

The Hospital Emergency Room Dashboard provides valuable insights into emergency department performance and patient management. It enables healthcare administrators to monitor key metrics, identify operational bottlenecks, and improve patient care through data-driven decision-making.

---

## 3. Tech Stack

- 📊 Power BI Desktop
- 🔄 Power Query
- 📈 DAX (Data Analysis Expressions)
- 🗄️ Microsoft Excel / CSV Dataset
- 🎨 Power BI Visualizations & Slicers

---

## 4. Data Source

The dataset contains emergency room patient records, including:

- Patient ID
- Admission Date
- Patient Age
- Gender
- Waiting Time
- Admission Status
- Department Referral
- Patient Satisfaction Score

> Note: Dataset used for learning, analysis, and dashboard development purposes.

---

## 5. Features

- ✅ Total Patients KPI
- ✅ Average Waiting Time Analysis
- ✅ Patient Satisfaction Monitoring
- ✅ Admission vs Non-Admission Analysis
- ✅ Gender Distribution
- ✅ Age Group Analysis
- ✅ Department Referral Tracking
- ✅ Monthly Patient Trends
- ✅ Interactive Filters and Slicers
- ✅ Professional Dark Theme Dashboard

---

## 6. Key Business Questions Solved

1. How many patients visited the emergency room?
2. What is the average waiting time for patients?
3. What percentage of patients were admitted?
4. Which departments received the highest referrals?
5. Which age group contributes the most ER visits?
6. How does patient satisfaction change over time?
7. What are the monthly trends in patient volume?
8. What is the gender distribution of patients?
9. Which periods experience peak emergency room traffic?

---
